### Retail Sales and Profit Analysis
Turning data into decisions.
A Data Analyst portfolio project focused on discovering business insights using Excel, SQL and Power BI.

# Business Vision
To understand what drives retail sales, uncover profit opportunities, and turn raw data into meaningful business decisions.

# Tools
EXCEL- Data cleaning and analysis
SQL- Data querying and business insights
POWER BI- Interactive dashboards and visualization

# Business Questions
1. Which product categories generate the highest sales?
2. Which regions generate the highest profit?
3. How do discounts affect profitability?
4. Which products are making losses?
5. What are the monthly sales trends?


# Project Workflow
1. Explore the dataset
2. Clean and prepare the data using Excel
3. Analyse business performance using SQL
4. Building interactive Power BI dashboard
5. Present findings and Business recommendation
